# 10 — Validação final

Referência: [main.md](main.md) → "Critérios de aceite".

Depende de: 01–09

## Objetivo

Verificar o app ponta a ponta contra todos os critérios de aceite de `main.md`.

## Escopo

- Preparar arquivos de teste (fora do bundle, ex.: `fixtures/`):
  - `.xlsx` com várias abas (só a primeira deve ser lida);
  - `.xls`;
  - `.csv` com vírgula decimal;
  - coordenadas vazias, não numéricas e fora do intervalo;
  - arquivo com coluna `Região` já existente;
  - cabeçalho fora da primeira linha (com linhas de título acima);
  - linhas totalmente vazias no meio dos dados;
  - 103 clientes válidos (cenário 10 × 10 + 3).
- Percorrer cada item de "Critérios de aceite" de `main.md` no navegador e marcar.
- Revisar layout da sidebar (alinhamento, estados desabilitados, mensagens de erro).
- Rodar `npm run test`, `npm run lint`, `npx tsc --noEmit`, `npm run build`.

## Critérios de aceite

- [ ] Todos os critérios de `main.md` marcados.
- [ ] Testes, lint, typecheck e build passam.
